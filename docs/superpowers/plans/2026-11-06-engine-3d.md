# 3D 4-Stroke Engine Explainer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static website that teaches students the 4-stroke engine through a scroll-driven 3D walkthrough followed by an interactive inline-4 sandbox.

**Architecture:** Plain ES modules, no build. All motion derives from one crank angle θ (0–720°) fed through pure kinematics functions; Three.js meshes are built procedurally and only `engine.update(θ)` moves them. Two views: a sticky stage canvas (hero + walkthrough) and a sandbox canvas, each with its own renderer, only the visible one renders.

**Tech Stack:** Three.js 0.160.0 via import map (jsDelivr), `three/addons` (OrbitControls, CSS2DRenderer), Node 24 built-in test runner, `python3 -m http.server` for local serving, Playwright for screenshot checks.

**Spec:** `docs/superpowers/specs/2026-11-06-engine-3d-design.md`

## Global Constraints

- Static files only; no npm dependencies, no bundler. `package.json` exists only to set `"type": "module"` and a `test` script.
- Three.js pinned exactly: `https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js`, addons under `https://cdn.jsdelivr.net/npm/three@0.160.0/examples/jsm/`.
- `js/kinematics.js` and the pure export of `js/scroll.js` must not import Three.js or touch the DOM at module top level (Node imports them in tests).
- Engine numbers: bore 86 mm, stroke 86 mm, crank radius 43 mm, rod 143 mm, compression ratio 10:1, max valve lift 9 mm, intake 0–180°, exhaust 540–720°, firing order 1-3-4-2.
- Scene scale: 1 Three.js unit = 10 mm. Cylinder spacing 100 mm (10 units).
- Sandbox: RPM 0–6000, animation at RPM/100, label "shown at 1/100 speed".
- Colors: intake mixture `#3b82f6`, compressed mixture `#facc15`, combustion `#f97316`, exhaust `#9ca3af`.
- Out of scope: sound, quizzes, other engine types, translations, backend.
- Desktop is the target; at ≤ 768 px width the layout stacks (stage above panels) and nothing overflows horizontally.
- Commit messages: plain, no AI attribution.

## Review Focus

1. **Page loaded or reloaded mid-walkthrough** → engine shows the θ for that scroll position immediately (θ comes from absolute scroll progress, never accumulated deltas). Pinned by `scrollState` tests in Task 4 and a reload check in Task 6.
2. **Stepping backward past 0° / negative θ** → wraps to 715°, stroke reads "exhaust", never NaN or negative. Pinned by `wrapTheta`/`strokeAt` tests in Task 1.
3. **Tab hidden then shown again** (huge frame dt) → engine advances at most 0.1 s worth, no jump. Pinned by `advanceTheta` clamp test in Task 1.
4. **Browser window resized** → canvases and cameras keep correct aspect, no stretching. Manual check in Task 6.
5. **`prefers-reduced-motion: reduce`** → hero does not idle-animate and sandbox starts paused; scroll-driven motion still works (user-initiated). Checked in Task 6 via Playwright `emulateMedia`.

### Task 1: Kinematics (pure maths) + test harness

**Files:**
- Create: `package.json`, `js/kinematics.js`
- Test: `test/kinematics.test.js`

**Interfaces:**
- Produces (all named exports of `js/kinematics.js`):
  - Constants: `BORE = 86`, `STROKE = 86`, `R = 43`, `L = 143`, `CR = 10`, `MAX_LIFT = 9`, `INTAKE = [0, 180]`, `EXHAUST = [540, 720]`, `FIRING_ORDER = [1, 3, 4, 2]`
  - `wrapTheta(theta: number) → number` in `[0, 720)`
  - `pistonY(theta: number, r = R, l = L) → number` mm above crank axis
  - `valveLift(theta: number, [opens, closes]: [number, number], maxLift = MAX_LIFT) → number` mm, 0 outside the window
  - `strokeAt(theta: number) → "intake" | "compression" | "power" | "exhaust"`
  - `cylinderPhase(i: number, order = FIRING_ORDER) → number` degrees; cylinder i's local angle is `wrapTheta(theta − cylinderPhase(i))`
  - `advanceTheta(theta: number, rpm: number, dtSeconds: number) → number` wrapped

- [ ] **Step 2: Write the failing tests** in `test/kinematics.test.js` using `node:test` and `node:assert/strict`:

```js
test('pistonY: TDC at 0/360, BDC at 180/540, travel = stroke', () => {
  const tdc = pistonY(0), bdc = pistonY(180);
  close(pistonY(360), tdc); close(pistonY(540), bdc);
  close(tdc - bdc, STROKE);
  for (let t = 0; t < 720; t += 5) assert.ok(pistonY(t) <= tdc + 1e-9 && pistonY(t) >= bdc - 1e-9);
});
test('pistonY is exact slider-crank, not a sine', () => {
  close(pistonY(90), Math.sqrt(L * L - R * R)); // ≈ 136.4, not the midpoint 143
});
test('valves closed through compression and power', () => {
  for (let t = 180; t <= 540; t += 1) { close(valveLift(t, INTAKE), 0); close(valveLift(wrapTheta(t), EXHAUST), 0); }
});
test('valve lift peaks at window midpoint', () => {
  close(valveLift(90, INTAKE), MAX_LIFT); close(valveLift(630, EXHAUST), MAX_LIFT);
});
test('strokeAt', () => {
  assert.equal(strokeAt(90), 'intake'); assert.equal(strokeAt(270), 'compression');
  assert.equal(strokeAt(450), 'power'); assert.equal(strokeAt(630), 'exhaust');
  assert.equal(strokeAt(-90), 'exhaust'); assert.equal(strokeAt(810), 'intake');
});
test('wrapTheta', () => {
  assert.equal(wrapTheta(-5), 715); assert.equal(wrapTheta(720), 0); assert.equal(wrapTheta(1445), 5);
});
test('inline-4: exactly one cylinder in power at any θ, firing 1,3,4,2', () => {
  const local = (t, i) => wrapTheta(t - cylinderPhase(i));
  const fired = [];
  for (let t = 0; t < 720; t += 1) {
    const inPower = [1, 2, 3, 4].filter(i => strokeAt(local(t, i)) === 'power');
    assert.equal(inPower.length, 1);
    if (fired.at(-1) !== inPower[0]) fired.push(inPower[0]);
  }
  // rotate so the sequence starts at cylinder 1
  const k = fired.indexOf(1); assert.deepEqual([...fired.slice(k), ...fired.slice(0, k)], [1, 3, 4, 2]);
});
test('advanceTheta: 6000 RPM shows 360°/s, rpm 0 stays, dt clamped to 0.1 s', () => {
  close(advanceTheta(0, 6000, 1 / 60) , 6);
  assert.equal(advanceTheta(100, 0, 0.5), 100);
  close(advanceTheta(0, 6000, 30), 36); // 30 s hidden tab → only 0.1 s applied
  close(advanceTheta(719, 6000, 0.1), 35);
});
```

where `close(a, b) = assert.ok(Math.abs(a - b) < 1e-6, \`${a} ≠ ${b}\`)` (same helper in Task 4's test).

- [ ] **Step 4: Implement `js/kinematics.js`**

- `pistonY`: `r·cos θ + √(l² − r²·sin² θ)` (θ in radians inside).
- `valveLift`: inside `[opens, closes]` return `maxLift · sin²(π · (θ − opens) / (closes − opens))`; wrap θ first. Lift is 0 at both window ends, so θ = 0 vs 720 needs no special case.
- `strokeAt`: index `Math.floor(wrapTheta(θ) / 180)` into the 4 names.
- `cylinderPhase`: `180 · order.indexOf(i)`.
- `advanceTheta`: `wrapTheta(θ + rpm · 0.06 · Math.min(dt, 0.1))` (rpm/100 rev/min → 360°·rpm/6000 per s = 0.06·rpm °/s).
- `wrapTheta`: `((θ % 720) + 720) % 720`.

Run: `npm test`
Expected: all 8 tests PASS.

- [ ] **Step 3: Implement `js/engine.js`**

Per cylinder i (x offset `(i − 1 − (n−1)/2) · 10` units): piston (cylinder Ø 8.6 units), rod (box from crank pin to piston pin), crank throw + counterweight on a shared crankshaft along x, head with intake valve (blue-tinted) and exhaust valve (red-tinted) stems + heads, spark plug, shared camshaft above with one lobe per valve. Semi-transparent block (`opacity 0.25`, `depthWrite false`) that `setCutaway(true)` hides.

`update(theta)`: for each cylinder, `local = wrapTheta(theta − cylinderPhase(i))`; piston y = `pistonY(local) / 10`; crank pin at angle `local`; rod positioned at the midpoint of pin↔piston pin, rotated to point between them; crankshaft rotation = `theta` (radians); camshaft rotation = `theta / 2`; intake/exhaust valve moved down by `valveLift(local, INTAKE|EXHAUST) / 10`. For the 4-cylinder build, crank throws are at the angles their phases imply (1 & 4 together, 2 & 3 opposite).

Use `MeshStandardMaterial`, distinct colours per part type, shadows on (desktop target).

### Task 4: Scroll-driven walkthrough

**Files:**
- Create: `js/scroll.js`, `test/scroll.test.js`
- Modify: `index.html` (panel copy), `js/main.js` (scroll controls θ, part labels, 1→4 switch, camera pull-back)

**Interfaces:**
- Consumes: Task 2 ids, `createEngine`, `labelAnchors`; Task 3 `createEffects`.
- Produces (`js/scroll.js`):
  - `scrollState(progress: number) → { step: "parts" | "intake" | "compression" | "power" | "exhaust" | "multi", theta: number, cylinders: 1 | 4, stepProgress: number }` — pure. `progress` is clamped to [0, 1] and split into 6 equal slices in step order. `parts`: θ = 0. Each stroke step maps its slice linearly onto its 180° range (intake 0→180 … exhaust 540→720), θ returned through `wrapTheta`. `multi`: θ 0→720, `cylinders: 4`; all others `cylinders: 1`.
  - `initScroll(section: HTMLElement, onState: (state) => void) → void` — computes progress from `section.getBoundingClientRect()` (absolute, not deltas), calls `onState` on `scroll`, `resize`, and once immediately; sets `.active` on the `.panel[data-step]` matching `state.step`.
